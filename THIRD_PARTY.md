# React Bits

Ten animation components are imported directly from the official [React Bits repository](https://github.com/DavidHDev/react-bits), commit `e1bbb696fc53f7f91e694c529e4d68c899773b6e`.

Aurora, SpotlightCard, Magnet, ClickSpark, CountUp, BlurText, FadeContent, AnimatedContent, StarBorder and ShinyText are vendored in `components/react-bits/`. Their upstream license is preserved there. These are real source imports, not imitations. Local CSS adapts styling; wrappers honor reduced motion. CountUp finishes at the exact target at its configured duration to keep currency values precise. Daygraph is a private personal application preview.
